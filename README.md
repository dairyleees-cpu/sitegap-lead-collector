SiteGap Lead Collector

Бесплатный сборщик потенциальных клиентов для SiteGap.

Цель проекта

Сбор минимум 300 уникальных реальных организаций из России, у которых в OpenStreetMap не указан сайт.

Возможности

* Поиск организаций по городам и регионам России
* Поиск по категориям бизнеса
* Получение телефонов и адресов, если они доступны
* Фильтрация организаций без указанного сайта
* Удаление дублей
* Сохранение результатов
* Экспорт CSV для SiteGap

Источник данных

OpenStreetMap и Overpass API.

Важно

Отсутствие сайта в OpenStreetMap не означает, что у организации действительно нет сайта. Данные необходимо проверять.

Статус
